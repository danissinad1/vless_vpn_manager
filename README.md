# 🛡️ VLESS VPN Manager

Интерактивный консольный менеджер для установки, настройки, диагностики и обслуживания VLESS VPN на базе **sing-box** и **Xray**.

Менеджер хранит несколько VLESS-ссылок, проверяет каждый узел через ChatGPT и Gemini, выбирает рабочие серверы, безопасно применяет конфигурацию и автоматически откатывает неудачные изменения.

> [!WARNING]
> Проект изменяет сетевую конфигурацию Linux, управляет systemd-сервисами и может удалять VPN-конфигурацию. Перед использованием обеспечьте резервный канал доступа к серверу. Не публикуйте свои VLESS-ссылки: они содержат UUID и параметры доступа.

## ✨ Возможности

- 🎨 цветное интерактивное меню и информационная панель;
- 🔍 диагностика sing-box, Xray, systemd, DNS, ChatGPT, Gemini и YouTube;
- 🗂️ добавление, редактирование и удаление VLESS-ссылок;
- 📥 импорт VLESS-ссылок из обычных и Base64-кодированных HTTP(S)-подписок;
- 🧪 изолированная проверка каждого узла;
- 🤖 автоматический выбор узлов с доступом к ChatGPT и Gemini;
- 🔀 объединение рабочих узлов в селектор `vpn-auto`;
- 🧩 поддержка `VLESS + Reality/TCP`, `TLS/TCP` и `XHTTP/TLS`;
- 💾 резервное копирование перед изменениями;
- ↩️ автоматический откат при неудачном применении;
- 🕒 откат всех изменений текущего запуска;
- 🧹 полное удаление VPN с предварительным backup;
- ♻️ чистая переустановка sing-box и Xray;
- 🔒 блокировка одновременного запуска двух экземпляров;
- ⌨️ устойчивый ввод при переключении русской и английской раскладки.

## 🧱 Как это работает

```text
VLESS-ссылки
      │
      ▼
VLESS VPN Manager ──► проверка каждого узла
      │                  ├─ ChatGPT Codex API
      │                  └─ Google Gemini
      ▼
выбор рабочих узлов
      ├─ Reality/TCP и TLS/TCP ──► sing-box
      └─ XHTTP/TLS ──────────────► Xray (xray-hermes)
                                      │
                                      ▼
                              локальные SOCKS-outbound
                                      │
                                      ▼
                               sing-box vpn-auto
```

Native-подключения обслуживаются непосредственно sing-box. XHTTP-подключения поднимаются Xray и передаются в sing-box через локальные SOCKS-порты.

## 📦 Требования

- Debian или Ubuntu с `systemd`;
- права `root`;
- Python 3.10 или новее;
- доступ к настроенным APT-репозиториям Debian/Ubuntu; базовые пакеты `curl`, `unzip` и `ca-certificates` устанавливаются автоматически;
- доступ к GitHub API и релизам Xray;
- архитектура `x86_64/amd64` или `aarch64/arm64`;
- поддержка TUN и policy routing ядром Linux.

> [!NOTE]
> Установщик проекта проверяет и при необходимости устанавливает Python 3, `ca-certificates`, `curl` и `unzip`, после чего копирует менеджер и его core-компонент. Установку или переустановку sing-box и Xray выполняет пункт **10** меню. Если `sing-box` отсутствует в APT, менеджер подключает официальный репозиторий SagerNet. Если репозиторий не отдаёт пакет, используется официальный `.deb` из GitHub Releases с обязательной проверкой SHA256 из GitHub API.

## 🚀 Установка

```bash
git clone https://github.com/danissinad1/vless_vpn_manager.git
cd vless_vpn_manager
sudo ./install.sh
```

Запуск:

```bash
sudo vless-vpn-manager
```

После обновления репозитория повторно запустите установщик:

```bash
git pull --ff-only
sudo ./install.sh
```

### Что устанавливается

| Назначение | Путь |
|---|---|
| Интерактивный менеджер | `/usr/local/sbin/vless-vpn-manager` |
| Генератор конфигураций | `/usr/local/sbin/update-remnawave-nodes` |
| Список VLESS-ссылок | `/etc/vless-vpn-manager/links.txt` |
| Конфигурация sing-box | `/etc/sing-box/config.json` |
| Конфигурация Xray | `/etc/xray-hermes/config.json` |
| systemd-unit Xray | `/etc/systemd/system/xray-hermes.service` |
| Состояние менеджера | `/var/lib/vless-vpn-manager` |
| Резервные копии | `/root/vless-vpn-backups` |

Файл ссылок создаётся с правами `0600`, а каталог — `0700`.

Если при первой установке найден старый файл `/home/odmin/remnawave.txt`, установщик копирует его в новое стандартное расположение. Исходный файл не удаляется.

В верхней части меню отображаются состояния sing-box и Xray, автозапуск сервисов, число VLESS-ссылок, число активных узлов, наличие снимка для отката и итог последнего теста.

## 📖 Подробная инструкция по меню

### 1️⃣ Полная диагностика установки и подключения

Проверяет:

- наличие sing-box, Xray и core-компонента;
- наличие списка ссылок и конфигураций;
- синтаксис конфигураций;
- состояние и автозапуск systemd-сервисов;
- доступ к ChatGPT Codex API;
- доступ к Gemini;
- работу DNS и сетевого подключения.

Используйте после установки, перезагрузки, изменения конфигурации или при потере доступа к сервисам.

Для Codex API ожидается `HTTP 404`: для тестового URL такой ответ означает, что endpoint доступен. Для Gemini ожидается `HTTP 200`.

### 2️⃣ Показать ошибки сервисов и команды исправления

Показывает последние 80 сообщений уровня `warning` и выше из журналов:

```bash
journalctl -u sing-box
journalctl -u xray-hermes
```

Также выводит команды проверки конфигураций и перезапуска сервисов. Используйте, если сервис имеет состояние `failed` или диагностика обнаружила ошибку.

### 1️⃣3️⃣ Проверить текущий доступ к сервисам

Проверяет через активный в данный момент системный маршрут доступ к ChatGPT, Gemini и YouTube. Узлы не переключаются, конфигурация не изменяется:

- зелёный — сервис доступен, получен HTTP 2xx/3xx;
- жёлтый — сервис отвечает, но вернул HTTP 4xx;
- красный — соединение не установлено или получен HTTP 5xx.

### 3️⃣ Показать ссылки

Выводит таблицу серверов с номером строки, транспортом, адресом и портом. UUID скрывается. Дубликаты отмечаются отдельно.

Поддерживаемые комбинации:

- `Reality/TCP`;
- `TLS/TCP`;
- `XHTTP/TLS`.

### 4️⃣ Добавить ссылки

1. Выберите пункт `4`.
2. Вставляйте по одной ссылке формата `vless://...` или HTTP(S)-ссылке подписки.
3. После каждой ссылки нажимайте Enter.
4. Для завершения отправьте пустую строку.

Менеджер умеет извлекать VLESS-ссылки из обычного текста и Base64-кодированных подписок размером до 5 МБ. Формат проверяется, дубликаты не добавляются. Изменение списка не переключает VPN автоматически. Для проверки и применения используйте пункт **8**.

### 5️⃣ Редактировать ссылку

1. Выберите пункт `5`.
2. Укажите номер строки.
3. Вставьте новую VLESS-ссылку.
4. Подтвердите изменение ответом `y`.

Поддерживаются ответы `y`, `yes`, `д`, `да`. После редактирования примените список через пункт **8**.

### 6️⃣ Удалить ссылки

Введите номера через запятую, пробел или точку с запятой:

```text
2, 5, 8
```

Подтвердите удаление ответом `y`. Удалённый узел может оставаться в активной конфигурации до выполнения пункта **8**.

### 7️⃣ Проверить все узлы: ChatGPT + Gemini

Каждый уникальный сервер проверяется отдельно. Для уменьшения случайных результатов запрос к каждому сервису выполняется дважды.

Пример:

```text
строка 1 Reality/TCP ChatGPT=✓ OK Gemini=✓ OK
строка 2 TLS/TCP     ChatGPT=✓ OK Gemini=✗ 403/403
строка 3 XHTTP/TLS   ChatGPT=✗ 000/000 Gemini=✗ 000/000
```

Этот пункт только проверяет узлы и сохраняет результат. Активная конфигурация не изменяется.

### 8️⃣ Автовыбор и применение лучших узлов

Основной пункт для применения списка.

Алгоритм:

1. проверяет все узлы;
2. выбирает серверы с доступом одновременно к ChatGPT и Gemini;
3. если таких нет — использует узлы с доступом к ChatGPT;
4. если ChatGPT недоступен через все узлы — не меняет активную конфигурацию.

Перед применением создаётся backup. Новые конфигурации проверяются командами sing-box и Xray, затем сервисы перезапускаются и выполняется контрольный запрос. При любой ошибке менеджер восстанавливает предыдущие конфигурации.

### 9️⃣ Исправить базовую конфигурацию и автозапуск

Восстанавливает отсутствующие базовые конфиги, systemd-unit Xray и автозапуск сервисов. После исправления запускается диагностика.

Этот пункт не устанавливает отсутствующие бинарники. Для полной установки используйте пункт **10**.

### 🔟 Чистая переустановка VPN

Останавливает VPN, проверяет обязательные пакеты, переустанавливает sing-box, загружает последнюю версию Xray, проверяет SHA256 архива, пересоздаёт конфигурации и применяет сохранённые ссылки.

Перед установкой менеджер автоматически:

1. обновляет индекс APT;
2. устанавливает отсутствующие `ca-certificates`, `curl` и `unzip`;
3. проверяет наличие кандидата `sing-box` в APT;
4. если пакет недоступен — загружает официальный ключ и подключает `https://deb.sagernet.org/`;
5. повторно обновляет индекс APT и проверяет доступность пакета;
6. устанавливает и проверяет `sing-box`.

Репозиторий создаётся в `/etc/apt/sources.list.d/sagernet.sources`, ключ — в `/etc/apt/keyrings/sagernet.asc`. Если пакет остаётся недоступен, установка прекращается и предыдущая VPN-конфигурация восстанавливается.

Для запуска необходимо точно ввести:

```text
ЧИСТАЯ УСТАНОВКА
```

Существующие ссылки сохраняются. При ошибке предыдущая конфигурация восстанавливается автоматически. Операция временно прерывает VPN-соединение.

### 1️⃣1️⃣ Полностью удалить VPN

Удаляет:

- пакет и конфигурацию sing-box;
- бинарник, unit и конфигурацию Xray;
- VLESS-ссылки;
- результаты тестирования.

Менеджер, core-компонент и резервный архив сохраняются. Для подтверждения требуется точная фраза:

```text
УДАЛИТЬ VPN
```

> [!CAUTION]
> После выполнения VPN немедленно перестанет работать. Не используйте этот пункт без резервного способа подключения к серверу.

### 1️⃣2️⃣ Откатить все изменения текущего запуска

Перед первым изменением менеджер автоматически создаёт снимок состояния. Пункт `12` восстанавливает:

- список ссылок;
- конфигурации sing-box и Xray;
- бинарник Xray;
- состояние и автозапуск сервисов;
- результаты тестирования;
- установленную версию sing-box, если это возможно.

Снимок относится к текущему процессу менеджера. Архивы остаются в `/root/vless-vpn-backups/` и после выхода.

### 0️⃣ Выход

Закрывает менеджер. sing-box и Xray продолжают работать как systemd-сервисы.

## 🖥️ Командная строка

| Команда | Действие |
|---|---|
| `sudo vless-vpn-manager --diagnose` | полная диагностика |
| `sudo vless-vpn-manager --test` | проверка всех узлов |
| `sudo vless-vpn-manager --apply` | тестирование и применение без вопроса Y/N |
| `sudo vless-vpn-manager --repair` | восстановление базовой установки |
| `sudo vless-vpn-manager --clean-install` | чистая переустановка с защитной фразой |
| `sudo vless-vpn-manager --cleanup` | полное удаление с защитной фразой |
| `sudo vless-vpn-manager --list` | безопасный список ссылок без UUID |
| `sudo vless-vpn-manager --services` | текущий доступ к ChatGPT, Gemini и YouTube |
| `sudo vless-vpn-manager --self-test` | внутренний тест менеджера |

> [!IMPORTANT]
> Режим `--apply` не спрашивает подтверждение. Используйте его только после проверки списка ссылок.

## ⚙️ Переменные окружения

Для нестандартного размещения файлов доступны:

| Переменная | Значение по умолчанию |
|---|---|
| `VLESS_LINKS_FILE` | `/etc/vless-vpn-manager/links.txt` |
| `VLESS_MANAGER_CORE` | `/usr/local/sbin/update-remnawave-nodes` |
| `VLESS_SING_CONFIG` | `/etc/sing-box/config.json` |
| `VLESS_XRAY_CONFIG` | `/etc/xray-hermes/config.json` |
| `VLESS_XRAY_UNIT` | `/etc/systemd/system/xray-hermes.service` |
| `VLESS_STATE_DIR` | `/var/lib/vless-vpn-manager` |
| `VLESS_BACKUP_DIR` | `/root/vless-vpn-backups` |
| `VLESS_MANAGER_LOCK_FILE` | `/run/lock/vless-vpn-manager.lock` |
| `VLESS_CORE_LOCK_FILE` | `/run/lock/update-remnawave-nodes.lock` |

Пример:

```bash
sudo VLESS_LINKS_FILE=/root/my-links.txt vless-vpn-manager
```

Используйте одинаковое значение `VLESS_LINKS_FILE` для менеджера и core-компонента.

## 🔐 Безопасность и резервные копии

- список ссылок содержит секретные UUID — не добавляйте его в Git;
- перед изменениями создаётся snapshot;
- перед очисткой и переустановкой создаётся полный архив;
- конфигурации проверяются до замены рабочих файлов;
- опасные действия требуют точной защитной фразы;
- архивы доступны только root;
- одновременно может работать только один экземпляр менеджера;
- архивы проверяются на небезопасные пути перед восстановлением.

Резервные копии находятся в:

```text
/root/vless-vpn-backups/
```

## ⚠️ Ограничения

- автоматическая установка рассчитана на Debian/Ubuntu и APT;
- требуется systemd;
- проверка доступности зависит от текущих HTTP-ответов ChatGPT и Gemini;
